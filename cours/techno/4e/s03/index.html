Thème : Les objets et les systèmes techniques : leurs usages et leurs interactions à découvrir et à analyser

Problématique : Un robot aspirateur convient-il à tout le monde ?

Pourquoi étudier ce sujet ?

Objectif de cette séance : Comprendre qu’un même besoin peut conduire à plusieurs solutions techniques.

Dans la vie quotidienne

Pour chaque utilisateur, cherchez d’abord ce qui est important, puis ce qui peut compliquer le choix.

Pour commencer

Reprends les méthodes des séances précédentes si elles te sont utiles ; les rappels du cours t’accompagnent.

Ce que vous allez apprendre

  • Comprendre qu’un même besoin peut conduire à plusieurs solutions techniques.
  • Comprendre qu’une solution peut être adaptée à une situation et moins adaptée à une autre.
  • Comprendre que les contraintes influencent le choix d’une solution technique.

Ce que vous allez apprendre à faire

  • analyser une situation d’utilisation ;
  • identifier un besoin et des contraintes ;
  • formuler une première hypothèse ;
  • vérifier une information dans une documentation technique ;
  • choisir une solution et justifier ce choix.

Problématique : Une même solution technique peut-elle convenir à tous les utilisateurs et à toutes les situations ?

Lis les repères et observe ce qui est montré

  • 78 ans ;
  • appartement de 65 m² ;
  • peu de meubles au sol ;

  • maison de 140 m² sur deux étages ;

  • peu de meubles ;

Situation D : Camille

  • des seuils de porte assez hauts ;

Choisissez deux questions :

À toi d’essayer avec les questions

7. Choisir une solution adaptée

Lis les repères et observe ce qui est montré

Choisissez maintenant deux utilisateurs parmi les quatre.

Pour chacun, choisissez la solution qui vous semble la plus adaptée :

  • balai ;
  • aspirateur traîneau ;
  • aspirateur sans fil ;
  • robot aspirateur ;
  • combinaison de plusieurs solutions.

Présentez chaque choix sous la forme :

  • Solution choisie : ...
  • Besoin principal : ...
  • Deux contraintes prises en compte : ...
  • Pourquoi cette solution : ...
  • Une limite restante : ...

Plusieurs solutions peuvent être correctes si elles sont correctement justifiées.

Mission 10

8. Mettons des mots sur ce que nous avons découvert

Lis les repères et observe ce qui est montré

Un besoin correspond à ce qu’un utilisateur cherche à obtenir ou à réaliser.

Une contrainte est une condition que la solution doit respecter ou prendre en compte.

Deux utilisateurs ayant le même besoin peuvent donc choisir des solutions différentes parce que leurs contraintes ne sont pas les mêmes.

Une solution technique n’est pas « la meilleure » dans l’absolu : elle est plus ou moins adaptée à une situation donnée.
