Thème du programme

Les objets et les systèmes techniques : leurs usages et leurs interactions à découvrir et à analyser

Le problème à résoudre

Le robot aspirateur parfait existe-t-il ?

Ce que tu vas apprendre

  • Comprendre qu’une solution technique est conçue pour répondre à un besoin précis.
  • Comprendre que les contraintes et les critères ne sont pas les mêmes pour tous les utilisateurs.
  • Comprendre qu’améliorer une caractéristique peut en dégrader une autre.
  • Comprendre qu’une conception technique résulte souvent de compromis.

Ce que tu vas apprendre à faire

  • analyser un besoin ;
  • identifier et hiérarchiser des contraintes ;
  • choisir des caractéristiques cohérentes ;
  • justifier plusieurs choix techniques ;
  • identifier les limites de votre propre solution ;
  • réutiliser les méthodes étudiées lors des séances précédentes.

Mission 5

3. Votre mission : concevoir pour un utilisateur

Lis les repères et observe ce qui est montré

Vous devez concevoir un robot aspirateur pour un seul des profils suivants.

Profil A : petit logement, petit budget

  • appartement de 40 m² ;
  • sols principalement durs ;
  • aucun animal ;
  • peu d’obstacles ;
  • budget maximal : 250 € ;
  • priorité : simplicité et prix réduit.

Profil B : grande maison avec animaux

  • maison de 130 m² ;
  • deux chiens et un chat ;
  • plusieurs tapis ;
  • nettoyage presque quotidien ;
  • budget maximal : 650 € ;
  • priorité : efficacité du nettoyage.

Profil C : automatiser au maximum

  • logement de 90 m² ;
  • plusieurs pièces ;
  • sols principalement durs ;
  • budget maximal : 900 € ;
  • souhaite programmer le nettoyage ;
  • priorité : intervenir le moins souvent possible.

Profil D : conserver longtemps l’appareil

  • logement de 80 m² ;
  • budget maximal : 500 € ;
  • souhaite conserver le robot longtemps ;
  • souhaite pouvoir remplacer batterie, roues et brosses ;
  • souhaite limiter les remplacements prématurés ;
  • priorité : durée d’utilisation et réparabilité.

Mission 13

11. Mettons des mots sur ce que nous avons découvert

Lis les repères et observe ce qui est montré

Une solution technique doit répondre à un besoin tout en respectant plusieurs contraintes.

Des critères permettent de comparer ou d’évaluer plusieurs solutions.

Selon l’utilisateur, certains critères deviennent prioritaires alors que d’autres le sont moins.

Les critères peuvent également entrer en opposition :

  • performance et coût ;
  • autonomie et masse ;
  • nombre de fonctions et simplicité ;
  • rigidité et quantité de matière ;
  • prix réduit et réparabilité.

Le concepteur doit alors effectuer des compromis.

Une bonne solution technique n’est donc pas forcément la meilleure dans tous les domaines : elle est surtout adaptée au problème à résoudre.
