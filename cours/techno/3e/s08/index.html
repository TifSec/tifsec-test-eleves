Comment une information circule-t-elle dans un réseau ?

Thème : Structure, fonctionnement, comportement : des objets et des systèmes techniques à comprendre

Problématique : Comment une donnée sait-elle où aller lorsqu'elle circule dans un réseau informatique ?

Pourquoi étudier ce sujet ?

Objectif de cette séance : Un réseau informatique permet à plusieurs équipements de communiquer et d'échanger des données.

Dans la vie quotidienne

Utilise les situations et les documents de la séance pour mettre les notions en pratique.

Pour commencer

Reprends les méthodes des séances précédentes si elles te sont utiles ; les rappels du cours t’accompagnent.

Ce que vous allez apprendre

  • Un réseau informatique permet à plusieurs équipements de communiquer et d'échanger des données.
  • Un réseau local comporte des terminaux, des équipements de communication et des liaisons.
  • Chaque interface réseau doit pouvoir être identifiée.
  • Une adresse IP permet d'identifier une interface dans un réseau utilisant le protocole IP.
  • Un commutateur relie les équipements d'un même réseau local.
  • Un routeur permet de faire communiquer plusieurs réseaux.
  • Internet est constitué d'un grand nombre de réseaux interconnectés.

Ce que vous allez apprendre à faire

Compétence visée : Identifier les éléments d'un réseau et expliquer simplement la circulation des données

Objectifs d’apprentissage

Ce que les élèves vont apprendre :

  • Un réseau informatique permet à plusieurs équipements de communiquer et d'échanger des données.
  • Un réseau local comporte des terminaux, des équipements de communication et des liaisons.
  • Chaque interface réseau doit pouvoir être identifiée.
  • Une adresse IP permet d'identifier une interface dans un réseau utilisant le protocole IP.
  • Un commutateur relie les équipements d'un même réseau local.
  • Un routeur permet de faire communiquer plusieurs réseaux.
  • Internet est constitué d'un grand nombre de réseaux interconnectés.

Ce qu'ils vont apprendre à faire :

  • Identifier les principaux équipements d'un réseau informatique.
  • Associer un équipement à son rôle.
  • Repérer une adresse IP dans un document technique.
  • Reconstituer le trajet simplifié d'une donnée.
  • Distinguer communication dans un réseau local et communication entre plusieurs réseaux.
  • Justifier une réponse à partir d'un schéma ou d'adresses IP.

5. Et si la destination se trouve dans un autre réseau ?

Lis les repères et observe ce qui est montré

L'ordinateur 1 souhaite maintenant accéder à un serveur situé sur Internet.

Complétez le trajet simplifié :

Ordinateur → ................................ → ................................ → Internet → serveur distant

À toi d’essayer avec les questions

Question 1 — Q8 : Pourquoi le routeur devient-il nécessaire dans cette situation ?

Mise en commun : réseau local et routage

Le commutateur permet principalement de relier les équipements d'un réseau local.

Le routeur permet de transmettre des données entre plusieurs réseaux.

Internet est constitué d'un très grand nombre de réseaux reliés entre eux.
