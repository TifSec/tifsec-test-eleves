Ta mission du jourTechnologie · 3e · S09

Comment faire communiquer plusieurs réseaux ?

Thème du programme

Structure, fonctionnement, comportement : des objets et des systèmes techniques à comprendre

Le problème à résoudre

Pourquoi deux réseaux qui fonctionnent séparément ne peuvent-ils pas forcément communiquer entre eux ?

Ce que tu vas apprendre

  • Deux équipements appartenant au même réseau local peuvent communiquer directement par l'intermédiaire d'un commutateur.
  • Les adresses IP et le masque permettent de configurer les interfaces réseau.
  • Un routeur relie plusieurs réseaux différents.
  • Une passerelle indique à un équipement vers quel routeur envoyer les données destinées à un autre réseau.
  • Une erreur d'adresse, de masque ou de passerelle peut empêcher la communication.
  • La commande ping permet de tester si une machine est joignable.

Pourquoi cette séance ?

PC1 sait communiquer avec les machines de son réseau local.

Dans la vie quotidienne

Utilise les situations et les documents de la séance pour mettre les notions en pratique.

Objectifs d’apprentissage

Ce que les élèves vont apprendre :

  • Deux équipements appartenant au même réseau local peuvent communiquer directement par l'intermédiaire d'un commutateur.

  • Un routeur relie plusieurs réseaux différents.

Ce qu'ils vont apprendre à faire :

  • Observer le trajet des données dans une simulation.

3. Comment vérifier que le réseau fonctionne ?

Lis les repères et observe ce qui est montré

Vous allez utiliser la commande ping.

Pour ouvrir la ligne de commande dans Filius :

  1. Passez en mode simulation avec la flèche verte.
  2. Cliquez sur PC1.
  3. Ouvrez Installation des logiciels.
  4. Sélectionnez Ligne de commande dans les logiciels disponibles.
  5. Utilisez la flèche vers la gauche pour l'installer.
  6. Cliquez sur Appliquer les modifications.
  7. Ouvrez ensuite Ligne de commande.

Saisissez :

ping 192.168.1.11

7. Pourquoi le routeur ne suffit-il pas ?

Lis les repères et observe ce qui est montré

PC1 sait communiquer avec les machines de son réseau local.

Mais lorsqu'il veut atteindre 192.168.2.10, il doit savoir à quel équipement transmettre les données pour sortir de son réseau.

Sur PC1, configurez :

Passerelle : 192.168.1.1

Sur PC2 :

Passerelle : 192.168.1.1

Sur PC3 et PC4 :

Passerelle : 192.168.2.1

Refaites le test entre PC1 et PC3.

Mise en commun : la passerelle

Une passerelle indique à une machine vers quel équipement envoyer les données lorsqu'elles doivent quitter son réseau local.

Dans notre réseau, cette passerelle correspond à l'interface du routeur présente dans le même réseau que l'ordinateur.

Mission 14

À retenir

Lis les repères et observe ce qui est montré

Deux machines d'un même réseau local peuvent communiquer si leur configuration réseau est correcte.

La commande ping permet de vérifier qu'une machine est joignable.

Pour relier plusieurs réseaux, il faut utiliser un routeur.

La passerelle indique à un ordinateur vers quel routeur envoyer les données qui doivent quitter son réseau local.

Une panne réseau peut souvent être trouvée en vérifiant méthodiquement les connexions, adresses IP, masques, interfaces du routeur et passerelles.
