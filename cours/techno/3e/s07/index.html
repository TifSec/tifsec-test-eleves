Comment une machine utilise-t-elle des données ?

Thème : Structure, fonctionnement, comportement : des objets et des systèmes techniques à comprendre

Problématique : Comment un système automatisé transforme-t-il des informations du monde réel en données qu'il peut traiter ?

Pourquoi étudier ce sujet ?

Un système numérique doit finalement représenter ses informations à l'aide de deux états élémentaires.

Dans la vie quotidienne

Utilise les situations et les documents de la séance pour mettre les notions en pratique.

Pour commencer

Reprends les méthodes des séances précédentes si elles te sont utiles ; les rappels du cours t’accompagnent.

Ce que vous allez apprendre

  • Un système numérique utilise des données pour représenter des informations.
  • Une donnée peut notamment être un nombre, un booléen ou du texte.
  • Une donnée peut provenir d'un capteur, être produite par un programme ou être destinée à l'utilisateur.
  • Un booléen représente une information possédant deux états.
  • Dans un système numérique, l'information est représentée à l'aide de bits.
  • Un bit peut prendre deux valeurs et huit bits constituent un octet.
  • Les données peuvent être traitées, transmises ou stockées.

Ce que vous allez apprendre à faire

Compétence visée : Identifier les données utilisées par un système technique et comprendre leur rôle dans son fonctionnement

Objectifs d’apprentissage

Ce que les élèves vont apprendre :

  • Un système numérique utilise des données pour représenter des informations.
  • Une donnée peut notamment être un nombre, un booléen ou du texte.
  • Une donnée peut provenir d'un capteur, être produite par un programme ou être destinée à l'utilisateur.
  • Un booléen représente une information possédant deux états.
  • Dans un système numérique, l'information est représentée à l'aide de bits.
  • Un bit peut prendre deux valeurs et huit bits constituent un octet.
  • Les données peuvent être traitées, transmises ou stockées.

Ce qu'ils vont apprendre à faire :

  • Identifier les informations nécessaires au fonctionnement d'un système.
  • Identifier le type d'une donnée.
  • Associer une information à une donnée utilisée par un programme.
  • Interpréter une convention utilisant 0 et 1.
  • Exploiter une série de données pour déterminer le comportement attendu d'un système.
  • Justifier une réponse à partir d'une valeur et d'un seuil.

Activité 3 — 2. De quoi une cuve automatisée a-t-elle besoin pour fonctionner ?

On souhaite automatiser une cuve de récupération d'eau.

Le système doit pouvoir :

  • connaître le niveau d'eau ;
  • mettre une pompe en fonctionnement lorsque cela est nécessaire ;
  • indiquer l'état du système à l'utilisateur ;
  • conserver certaines mesures afin de suivre l'évolution du niveau.

Question 1 — Q1 : Quelles informations la machine doit-elle connaître pour pouvoir réaliser ces actions ?

Mise en commun : une information représentée par une donnée

Pour être utilisée par un système numérique, une information est représentée sous la forme d'une donnée.

Parmi les types de données que nous utiliserons cette année, on trouve notamment :

  • nombre : 72 ;
  • booléen : vrai ou faux ;

Activité 6 — 5. Pourquoi seulement des 0 et des 1 ?

Un système numérique doit finalement représenter ses informations à l'aide de deux états élémentaires.

Cette unité d'information est appelée un bit.

Un bit peut prendre deux valeurs :

0 ou 1.

Pour notre pompe, on choisit par exemple la convention :

  • 0 : pompe arrêtée ;
  • 1 : pompe en fonctionnement.

Activité 7 — 6. Un seul bit suffit-il pour tout représenter ?

Un bit ne possède que deux valeurs possibles.

Pour représenter davantage d'informations, les bits sont regroupés.

8 bits = 1 octet

Calculez :

  1. 4 octets = ............... bits ;
  2. 250 octets = ............... bits ;
  3. 2 000 octets = ............... bits.

Activité 12 — À retenir

Un système numérique utilise des données pour représenter les informations dont il a besoin.

Ces données peuvent notamment être des nombres, des booléens ou du texte.

Elles peuvent être acquises, traitées, transmises ou stockées.

Un bit peut prendre les valeurs 0 ou 1 et 8 bits constituent un octet.

Une donnée n'a de sens que si l'on connaît ce qu'elle représente, son unité ou la convention utilisée.
