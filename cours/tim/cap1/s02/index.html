Réponses aux activités

Activité 1 — Pour commencer

Un ordinateur peut contenir des milliers de fichiers. Aujourd'hui, nous allons apprendre à les ranger pour pouvoir les retrouver facilement.

Activité 2 — 1. Préparer le document de la séance

Ouvrez votre dossier :

MG1_INFORMATIQUE

Créez à l'intérieur un nouveau dossier nommé :

SEANCE_02

Ouvrez LibreOffice Writer puis enregistrez immédiatement votre document dans ce dossier sous le nom :

CAPA1_S02_nom_prenom.odt

Écrivez ensuite le titre :

Séance 2 — Ranger et retrouver ses fichiers

Activité 3 — 2. Fichier ou dossier ?

Un dossier sert à ranger et organiser des éléments.

Un fichier contient généralement un travail : texte, image, photographie, vidéo, tableau, PDF...

Dans votre document, recopiez puis complétez :

  • Un dossier sert à...
  • Un fichier sert à...
  • Le fichier que je suis en train de modifier s'appelle...
  • Il est enregistré dans le dossier...

Activité 4 — 3. Mission : préparer votre espace professionnel

Imaginez que vous allez utiliser votre ordinateur pendant toute votre formation et vos périodes de stage.

Dans votre espace personnel, créez un dossier nommé :

CAPA1

À l'intérieur, créez les trois dossiers suivants :

01_COURS 02_STAGES 03_DOCUMENTS

Dans le dossier 02_STAGES, créez ensuite :

ENTREPRISE PHOTOS DOCUMENTS_STAGE

Activité 5 — 4. Pourquoi ranger ?

Dans votre document de travail, répondez aux questions suivantes.

Question 1 — Pourquoi est-il utile de créer plusieurs dossiers ?

Question 2 — Pourquoi les noms comme document1, nouveau document ou truc ne sont-ils pas de bons noms de fichiers ?

Question 3 — Proposez un bon nom pour un compte-rendu de stage réalisé en octobre 2026.

Activité 6 — 5. Petite manipulation

Dans le dossier DOCUMENTS_STAGE, créez un nouveau document Writer.

Enregistrez-le sous le nom :

fiche_stage.odt

Écrivez simplement :

  • Nom de la structure de stage :
  • Commune :
  • Activité principale :
  • Métier que je souhaite découvrir :
  • Une chose que j'aimerais apprendre pendant mon stage :

Si vous ne connaissez pas encore votre lieu de stage, vous pouvez écrire À compléter.

Enregistrez puis fermez le fichier.

Essayez ensuite de le retrouver et de l'ouvrir à nouveau en passant par vos dossiers.

Activité 7 — 6. Votre arborescence

Dans votre document de séance, reproduisez l'organisation des dossiers que vous venez de créer :

CAPA1 ├── 01_COURS ├── 02_STAGES │ ├── ENTREPRISE │ ├── PHOTOS │ └── DOCUMENTS_STAGE └── 03_DOCUMENTS

Pour faire une barre verticale, utilisez le caractère pipe (|) avec la combinaison de touches Alt Gr + 6.

Entourez ou mettez en gras le dossier dans lequel se trouve fiche_stage.odt.

Activité 8 — 7. À retenir

  • Je donne un nom clair à mes fichiers.
  • Je range mes fichiers dans des dossiers adaptés.
  • Je vérifie où j'enregistre mon travail.
  • J'utilise Ctrl + S régulièrement.
  • Je dois être capable de retrouver un fichier après l'avoir fermé.

Activité 9 — 8. Rendu

Enregistrez une dernière fois votre document :

CAPA1_S02_nom_prenom.odt

Rendez-le selon la méthode indiquée par le professeur.

Le fichier doit être rendu même s'il est incomplet.
