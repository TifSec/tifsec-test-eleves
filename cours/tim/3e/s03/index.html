Comment organiser ses fichiers pour ne plus les perdre ?

Thème : TIM — Comment organiser ses fichiers pour ne plus les perdre ?

Problématique : Comment organiser ses fichiers pour ne plus les perdre ?

Pourquoi étudier ce sujet ?

La partie située à la fin du nom d'un fichier, généralement après un point, s'appelle son extension.

Dans la vie quotidienne

apprendre à organiser correctement ses fichiers et ses dossiers afin de retrouver rapidement son travail.

Pour commencer

Reprends les méthodes des séances précédentes si elles te sont utiles ; les rappels du cours t’accompagnent.

Ce que vous allez apprendre

  • Faire la différence entre un fichier et un dossier.
  • Comprendre le rôle d'une extension de fichier.
  • Comprendre l'intérêt d'une organisation en dossiers et sous-dossiers.
  • Comprendre qu'un même contenu peut exister sous plusieurs formats.
  • Comprendre la différence entre enregistrer et exporter un document.

Ce que vous allez apprendre à faire

  • Créer une arborescence de dossiers.
  • Nommer correctement un fichier.
  • Déplacer et retrouver un fichier.
  • Identifier le type d'un fichier grâce à son extension.
  • Enregistrer un document Writer.
  • Exporter ce document au format PDF.

Activité 3 — 1. Fichier ou dossier ? – 5 minutes

Lorsque nous utilisons un ordinateur, nous manipulons principalement des fichiers et des dossiers.

  • Un fichier contient des données : texte, image, son, vidéo, tableau, programme...
  • Un dossier permet de ranger des fichiers ou d'autres dossiers.

Question 1 — Question 1 : indiquez si chaque élément est probablement un fichier ou un dossier.

Activité 4 — 2. À quoi sert une extension ? – 5 minutes

La partie située à la fin du nom d'un fichier, généralement après un point, s'appelle son extension.

Elle permet notamment d'identifier son format.

ExtensionType de fichierExemple de logiciel
.odtDocument texte OpenDocumentLibreOffice Writer
.odsClasseur OpenDocumentLibreOffice Calc
.odpPrésentation OpenDocumentLibreOffice Impress
.pdfDocument destiné notamment à la consultationNavigateur ou lecteur PDF
.jpg / .pngImageVisionneuse d'image / navigateur

Question 1 — Question 2 : quelle extension utiliseriez-vous pour :

un document Writer que vous souhaitez encore modifier ;

un tableau créé avec Calc ;

une présentation créée avec Impress ;

Question 2 — une version terminée d'un document destinée surtout à être consultée ?

AIDE SI BESOIN – Choisir l'extension

Indice 1/3 : regardez le tableau situé juste au-dessus.

Indice 2/3 : Writer, Calc et Impress n'utilisent pas la même extension.

Indice 3/3 : Writer = .odt, Calc = .ods, Impress = .odp, consultation = souvent .pdf.

Activité 5 — 3. Construire une arborescence – 10 minutes

Quand tous les fichiers sont placés au même endroit, il devient difficile de retrouver rapidement son travail.

Une solution consiste à créer une arborescence de dossiers.

Dans votre espace personnel, créez l'organisation suivante :

TIM └── 4e3e ├── Cours ├── Travaux │ └── S03 └── Ressources

AIDE SI BESOIN – Créer l'arborescence

Indice 1/3 : commencez uniquement par créer le dossier TIM.

Indice 2/3 : ouvrez ensuite TIM avant de créer 4e3e.

Indice 3/3 : dans 4e3e, créez Cours, Travaux et Ressources. Entrez ensuite dans Travaux pour créer S03.

Activité 6 — 4. Donner un nom utile à un fichier – 5 minutes

Imaginez que le professeur reçoive les fichiers suivants :

  • document.odt
  • travail.odt
  • sansnom1.odt
  • montravailfinalvraimentfinal2.odt

Question 1 — Question 4 : quels problèmes ces noms peuvent-ils provoquer ?

Nous utiliserons une règle de nommage simple :

classe_seance_nom_prenom.extension

Exemple :

4e3e_S03_martin_lucas.odt

Question 2 — Question 5 : corrigez les deux noms suivants :

  1. travail.odt pour Lucas Martin, séance 3 ;
  2. document.pdf pour Inès Durand, séance 3.

AIDE SI BESOIN – Nommer correctement un fichier

Indice 1/3 : reprenez le modèle classe_seance_nom_prenom.

Indice 2/3 : aujourd'hui, la séance est S03.

Indice 3/3 : exemple : 4e3e_S03_martin_lucas.odt.

Activité 7 — 5. Créer le document de travail – 10 minutes

Ouvrez LibreOffice Writer.

Créez un nouveau document contenant :

  • votre nom et votre prénom ;
  • votre classe ;
  • le titre Séance 3 – Organiser ses fichiers ;
  • vos réponses aux questions 1 à 5.

Enregistrez le document dans :

TIM > 4e3e > Travaux > S03

sous le nom :

4e3e_S03_nom_prenom.odt

AIDE SI BESOIN – Enregistrer au bon endroit

Indice 1/3 : choisissez Enregistrer sous.

Indice 2/3 : retrouvez d'abord votre dossier TIM.

Indice 3/3 : ouvrez TIM → 4e3e → Travaux → S03 puis saisissez le nom demandé.

Activité 8 — 6. Même document, deux formats – 5 minutes

Votre fichier est actuellement au format ODT.

Il s'agit de votre fichier de travail Writer.

Nous allons maintenant créer une version au format PDF.

  1. Enregistrez d'abord votre travail avec Ctrl + S.
  2. Utilisez la fonction d'export au format PDF.
  3. Enregistrez le PDF dans le même dossier S03.
  4. Nommez-le 4e3e_S03_nom_prenom.pdf.

Question 1 — Question 6 : pourquoi les deux fichiers ne sont-ils pas identiques alors qu'ils contiennent presque le même document ?

Activité 9 — 7. Retrouver son fichier – 5 minutes

Fermez LibreOffice Writer.

Revenez dans le dossier TIM.

Sans utiliser la liste des fichiers récents :

  1. retrouvez votre dossier S03 ;
  2. retrouvez votre fichier ODT ;
  3. ouvrez-le ;
  4. ajoutez à la fin : Je sais retrouver un fichier dans une arborescence.
  5. enregistrez avec Ctrl + S.

AIDE SI BESOIN – Retrouver le fichier

Indice 1/3 : commencez dans le dossier TIM.

Indice 2/3 : souvenez-vous que votre travail se trouve dans le dossier Travaux.

Indice 3/3 : suivez TIM → 4e3e → Travaux → S03.

Activité 10 — 8. Vérification et rendu – 5 minutes

Vérifiez votre dossier S03.

Il doit contenir :

  • 4e3e_S03_nom_prenom.odt
  • 4e3e_S03_nom_prenom.pdf

Vérifiez également :

  • Mon fichier possède le bon nom.
  • Il se trouve dans le bon dossier.
  • J'ai répondu aux questions.
  • Mon fichier ODT s'ouvre correctement.
  • Mon fichier PDF s'ouvre correctement.

Déposez ensuite :

4e3e_S03_nom_prenom.odt

dans l'espace indiqué par le professeur.

Le fichier doit être rendu même si tout n'est pas terminé.

Activité 12 — À retenir

  • Un dossier sert à organiser des fichiers et d'autres dossiers.
  • Un fichier contient des données.
  • L'extension indique le format d'un fichier.
  • Une arborescence permet de ranger les documents de manière logique.
  • Un nom de fichier précis permet de retrouver et d'identifier plus facilement son travail.
  • Un fichier ODT peut servir de document de travail dans Writer.
  • Une version PDF peut être créée pour faciliter la consultation ou la transmission.
  • Je dois être capable de retrouver un fichier sans dépendre uniquement de la liste des documents récents.
