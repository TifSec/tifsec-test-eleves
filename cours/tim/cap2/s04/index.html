Thème du programme

TIM — Accueillir un nouvel équidé : vérifier et organiser les informations

Le problème à résoudre

Accueillir un nouvel équidé : vérifier et organiser les informations

Ce que tu vas apprendre

  • Comprendre pourquoi l'identification et la traçabilité des équidés sont importantes.
  • Distinguer une obligation réglementaire d'une bonne pratique professionnelle.
  • Identifier une source professionnelle fiable sur Internet.
  • Comprendre l'intérêt d'un document standardisé lors de l'arrivée d'un cheval.

Ce que tu vas apprendre à faire

  • Rechercher une information dans une source professionnelle.
  • Extraire les informations importantes d'une page Internet.
  • Créer une fiche professionnelle avec LibreOffice Writer.
  • Organiser des informations dans des tableaux.
  • Insérer des liens vers les sources utilisées.
  • Exporter un document professionnel au format PDF.

Pourquoi cette séance ?

Objectif de cette séance : Comprendre pourquoi l'identification et la traçabilité des équidés sont importantes.

Dans la vie quotidienne

Le responsable vous demande de préparer son dossier d'arrivée et de vérifier que les informations importantes ont bien été transmises.

Mission 8À commencer

8. Mission principale : créer la fiche d'accueil de Mistral

Transformez maintenant votre document Writer en une fiche professionnelle utilisable par l'écurie.

Ajoutez un titre :

FICHE D'ACCUEIL D'UN ÉQUIDÉ

Ajoutez ensuite plusieurs parties clairement identifiables.

A. Identification de l'équidé

Créez un tableau contenant au minimum :

  • nom ;
  • sexe ;
  • âge ;
  • numéro SIRE ;
  • nom du propriétaire.

B. Arrivée dans la structure

Ajoutez :

  • date d'arrivée ;
  • date de départ prévue ;
  • type de séjour : pension temporaire.

C. Vérifications lors de l'arrivée

Créez un tableau de contrôle ressemblant à celui-ci :

À toi d’essayer avec les questions

Question 1 — Complète le tableau ci-dessous.

Élément à vérifier Oui Non Observation
Document d'identification original présent
Numéro SIRE disponible
Coordonnées du propriétaire disponibles
Contact en cas de problème disponible
Entrée enregistrée dans le registre d'élevage

Complétez ce tableau avec les informations disponibles concernant Mistral.

D. Observations

Ajoutez une zone suffisamment grande pour permettre à un salarié de noter des informations utiles lors de l'arrivée.

Pour cette activité, indiquez :

Document d'identification original à demander au propriétaire. Entrée de Mistral à enregistrer dans le registre.

Mission 11

11. Mission : informer le responsable

Sous votre fiche, rédigez un court message professionnel de 3 à 5 lignes destiné au responsable de l'écurie.

Votre message doit expliquer :

  • ce qui manque actuellement dans le dossier de Mistral ;
  • ce qui doit être mis à jour dans le registre ;
  • pourquoi il est important de corriger ces éléments.

Mission 12

12. Transformer la fiche en modèle professionnel

Améliorez la présentation de votre document :

  • titre clairement identifiable ;
  • sous-titres cohérents ;
  • tableaux lisibles ;
  • marges régulières ;
  • police facile à lire ;
  • aucun élément décoratif inutile.

Votre objectif est qu'un salarié puisse retrouver une information en quelques secondes.

13. Défi — Créer une fiche réutilisable

Si vous avez terminé, créez une deuxième page contenant la même fiche mais sans les informations concernant Mistral.

Elle doit pouvoir être imprimée et utilisée lors de l'arrivée de n'importe quel nouvel équidé.

Remplacez les informations par des zones à compléter :

  • Nom : ____________________

  • Date d'arrivée : ____________________

Vous venez ainsi de créer un modèle de document professionnel.

Mission 15

15. Rendu du travail

Avant de rendre votre fichier, vérifiez que :

  • la fiche permet d'identifier clairement Mistral ;
  • les informations d'arrivée sont présentes ;
  • le tableau de vérification est complété ;
  • les deux problèmes du dossier ont été repérés ;
  • vous distinguez obligations et organisation interne ;
  • les sources IFCE apparaissent avec des liens cliquables ;
  • le message destiné au responsable est rédigé ;
  • le document reste lisible et professionnel.

Rendez :

CAPA2_S04_NOM_Prenom.pdf

Même si votre travail n'est pas terminé, il doit être rendu.

Mission 16

À retenir

  • Une information professionnelle doit provenir d'une source identifiable et fiable.
  • Tout équidé doit être correctement identifié et enregistré.
  • Le document d'identification accompagne le cheval lors de ses déplacements.
  • Les mouvements des équidés doivent pouvoir être retrouvés dans le registre d'élevage.
  • Un document numérique professionnel doit permettre de retrouver rapidement les informations utiles.
  • Une source utilisée dans un travail doit être indiquée et, lorsque cela est possible, reliée à la ressource originale.
