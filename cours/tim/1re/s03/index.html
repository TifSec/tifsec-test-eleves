Activité 2 — 2. Situation professionnelle

Une structure équestre enregistre régulièrement des informations concernant les chevaux présents dans son écurie.

Le fichier contient notamment :

  • un identifiant de relevé ;
  • le nom du cheval ;
  • la date du relevé ;
  • son poids estimé ;
  • la quantité quotidienne de foin distribuée ;
  • son nombre d'heures de travail par semaine ;
  • son statut actuel.

Ces données pourraient ensuite servir à suivre les animaux, préparer des calculs, observer une évolution ou aider le responsable de la structure à prendre certaines décisions.

Mais le fichier a été complété par plusieurs personnes et toutes n'ont pas utilisé les mêmes méthodes de saisie.

Votre mission : rendre ce fichier propre et exploitable sans inventer de données.

Sources professionnelles utilisées pour construire l'activité :

  • IFCE – équipédia : Estimation du poids
  • IFCE – équipédia : Les besoins alimentaires du cheval
  • Chlorofil – Document d'accompagnement du module MG1 du Bac professionnel

IFCE – équipédia : Estimation du poids

IFCE – équipédia : Les besoins alimentaires du cheval

Chlorofil – Document d'accompagnement du module MG1 du Bac professionnel

Les chevaux et les relevés de cette activité sont fictifs. Les valeurs ont été simplifiées et adaptées pédagogiquement à partir de références professionnelles afin de proposer une situation réaliste. Elles ne constituent pas des recommandations individuelles d'alimentation ou de suivi des animaux.

Activité 3 — 3. Première mission : trouvez les problèmes

Observez attentivement la feuille DONNEES_BRUTES.

Ne modifiez encore aucune cellule.

Votre première mission consiste à repérer ce qui pourrait empêcher un ordinateur d'utiliser correctement ces données.

Vous pouvez notamment rechercher :

  • des différences d'écriture ;
  • des formats différents ;
  • des valeurs manquantes ;
  • des valeurs qui semblent surprenantes ;

  • des nombres qui semblent avoir été enregistrés comme du texte ;

Activité 5 — 5. Comment organiser correctement des données ?

Pour qu'un tableau soit facilement exploitable par un ordinateur, nous allons respecter trois règles simples :

  • Une ligne = une observation.
  • Une colonne = une information.
  • Une cellule = une valeur.

Exemple :

ChevalPoids estimé (kg)Foin distribué (kg/jour)
Volcan52010

Il est préférable d'écrire 10 dans la cellule plutôt que 10 kg.

L'unité kg/jour est déjà indiquée dans le titre de la colonne.

Calc pourra ainsi reconnaître la valeur comme un nombre et l'utiliser directement dans des calculs.

Activité 7 — 7. Mission : uniformisez les textes

Travaillez maintenant uniquement dans DONNEES_NETTOYEES.

Observez la colonne Cheval.

Les noms doivent tous respecter la même présentation :

Première lettre en majuscule, autres lettres en minuscules.

Exemple :

VOLCAN → Volcan

Faites ensuite de même avec la colonne Statut.

Les seules valeurs utilisées seront :

  • Actif
  • Repos
  • Soins

Vous pouvez modifier les cellules une par une ou rechercher une méthode permettant de remplacer plusieurs valeurs rapidement.

Indice : cherchez la fonction Rechercher et remplacer.

Activité 8 — 8. Mission : remettez les nombres au propre

Observez les colonnes :

  • Poids estimé (kg) ;
  • Foin distribué (kg/jour) ;
  • Travail par semaine (h).

Ces colonnes doivent contenir uniquement des nombres.

Corrigez les cellules contenant directement une unité, par exemple :

11 kg → 11

Vérifiez également les valeurs décimales.

Elles doivent être reconnues par Calc comme de véritables nombres et non comme du texte.

Activité 9 — 9. Mission : uniformisez les dates

Une même date peut être écrite de plusieurs manières :

  • 05/09/2026
  • 5/9/26
  • 05-09-2026
  • 5 septembre 2026

Pour une personne, ces écritures peuvent représenter la même information.

Pour un tableur, certaines peuvent être reconnues comme des dates et d'autres comme du texte.

Dans cette activité, toutes les dates devront être de véritables dates Calc et être affichées sous la forme :

JJ/MM/AAAA

Exemple :

05/09/2026

Uniformisez toutes les dates du tableau.

Activité 11 — 11. Mission : une donnée semble anormale

Une ligne du fichier indique un poids estimé de :

52 kg

Cette valeur est très différente des autres observations du fichier.

L'IFCE rappelle que le poids vif est notamment utilisé pour établir une ration, suivre l'état d'un cheval ou adapter certains traitements.

Il est donc particulièrement important que cette donnée soit fiable.

Quelle solution vous semble la plus professionnelle ?

  1. Remplacer automatiquement 52 par 520.
  2. Supprimer la ligne.
  3. Conserver temporairement la valeur et signaler qu'elle doit être vérifiée.
  4. Retrouver le relevé original pour contrôler la valeur avant de la modifier.

Expliquez votre choix dans la feuille DIAGNOSTIC.

Une donnée surprenante n'est pas automatiquement une donnée fausse.

Si vous ne disposez pas de la source originale, vous ne connaissez pas la bonne valeur.

Activité 12 — 12. Une référence professionnelle peut-elle corriger une donnée ?

L'IFCE indique que la quantité de fourrage distribuée dépend notamment du poids vif et précise des ordres de grandeur exprimés en pourcentage de ce poids.

Une référence professionnelle peut donc nous aider à détecter qu'une valeur mérite d'être vérifiée.

Mais peut-elle nous permettre de connaître automatiquement la vraie valeur contenue dans le relevé original ?

Répondez dans DIAGNOSTIC et justifiez.

Activité 13 — 13. Mission : cherchez le doublon

Une observation a été enregistrée deux fois dans le fichier.

Retrouvez les deux lignes concernées.

Comparez attentivement :

  • l'identifiant ;
  • le cheval ;
  • la date ;
  • le poids ;
  • le foin distribué ;
  • le temps de travail ;
  • le statut.

Si les deux lignes correspondent exactement à la même observation, conservez-en une seule dans DONNEES_NETTOYEES.

Dans DIAGNOSTIC, indiquez :

  • l'identifiant concerné ;
  • comment vous avez déterminé qu'il s'agissait réellement d'un doublon.

Activité 14 — 14. Contrôlez votre fichier

Avant de terminer, vérifiez votre feuille DONNEES_NETTOYEES.

Elle doit respecter les règles suivantes :

  • chaque ligne correspond à une observation ;
  • les noms des chevaux utilisent la même présentation ;
  • les statuts sont uniquement Actif, Repos ou Soins ;
  • les colonnes numériques contiennent uniquement des nombres lorsque la donnée est connue ;
  • les unités sont indiquées dans les titres et non dans les cellules ;
  • les dates utilisent le même format et sont reconnues comme des dates ;
  • les données manquantes sont signalées ;
  • les données douteuses sont signalées et non inventées ;
  • le doublon a été supprimé ;
  • la feuille DONNEES_BRUTES est toujours intacte.

Activité 15 — 15. Pourquoi nettoyer les données ?

Imaginez maintenant que l'on demande à Calc de calculer :

  • le poids moyen des chevaux ;
  • la quantité totale de foin distribuée ;
  • le nombre de chevaux actifs ;
  • l'évolution du poids d'un cheval au cours du temps.

Si certaines données sont enregistrées comme du texte, dupliquées, manquantes ou incorrectes, les résultats peuvent être faux.

L'ordinateur peut effectuer un calcul parfaitement juste à partir de données incorrectes et produire malgré tout une conclusion fausse.

La qualité d'une analyse dépend donc aussi de la qualité des données utilisées.

Dans votre feuille DIAGNOSTIC, répondez avec vos propres mots :

Question 1 — Pourquoi faut-il nettoyer les données avant de les analyser ?

Question 2 — Pourquoi faut-il conserver les données originales ?

Question 3 — Que faut-il faire lorsqu'une donnée semble fausse mais que l'on ne connaît pas la bonne valeur ?

Question 4 — Quelle différence faites-vous maintenant entre une donnée anormale et une donnée fausse ?

Activité 16 — À retenir

  • Des données doivent être organisées, cohérentes et vérifiables avant d'être analysées.
  • Une ligne = une observation.
  • Une colonne = une information.
  • Une cellule = une valeur.
  • Les nombres doivent rester des nombres : les unités sont de préférence indiquées dans les titres de colonnes.
  • Les formats doivent être cohérents dans l'ensemble du tableau.
  • Un doublon peut fausser les résultats d'une analyse.
  • Une donnée manquante ne doit pas être inventée.
  • Une donnée inhabituelle doit être contrôlée avant d'être corrigée.
  • Une source professionnelle peut aider à détecter une incohérence mais ne permet pas forcément de retrouver la vraie valeur.
  • Il est important de conserver les données brutes avant toute modification.
  • Une correction doit pouvoir être justifiée et tracée.
