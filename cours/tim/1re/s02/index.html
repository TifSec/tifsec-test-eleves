Thème du programme

TIM — Comprendre ce que racontent les données

Le problème à résoudre

Comprendre ce que racontent les données

Ce que tu vas apprendre

  • Une donnée est une valeur brute que l'on observe, mesure ou enregistre.
  • Une information est obtenue lorsque l'on donne du sens à une ou plusieurs données.
  • Une donnée doit être accompagnée de son contexte pour être correctement comprise.
  • Un tableau permet d'organiser plusieurs données pour pouvoir les comparer et les analyser.
  • Les données peuvent être de différentes natures : texte, nombre, date, catégorie, etc.
  • Un tableur comme Calc permet de traiter rapidement une grande quantité de données.

Pourquoi cette séance ?

Avec seulement huit chevaux, il est encore possible d'observer le tableau et de réaliser certains calculs manuellement.

Mission 2

2. Une structure équestre produit-elle des données ?

Une structure équestre produit et utilise chaque jour de nombreuses données.

Par exemple :

  • le nom des chevaux ;
  • leur âge ;
  • leur poids estimé ;
  • la quantité de fourrage distribuée ;
  • leur activité ;
  • les dates de soins ou d'interventions ;
  • le nombre de cavaliers ;
  • les stocks disponibles ;
  • les dépenses et recettes de la structure.

Tous ces éléments peuvent devenir des données lorsqu'ils sont enregistrés.

L'IFCE (Institut Français du Cheval et de l'Équitation) rappelle par exemple que connaître le poids vif d'un cheval (son poids sur pied, animal vivant) est utile pour établir une ration, suivre sa croissance ou son état et adapter certains traitements.

Les données ont donc une utilité concrète dans le fonctionnement d'une entreprise.

Sources professionnelles :

  • IFCE – équipédia : Estimation du poids.
  • IFCE – équipédia : Les besoins alimentaires du cheval.
  • Chlorofil – Document d'accompagnement du module MG1 du Bac professionnel.

IFCE – équipédia : Estimation du poids.

IFCE – équipédia : Les besoins alimentaires du cheval.

Chlorofil – Document d'accompagnement du module MG1 du Bac professionnel.

Les chevaux et les relevés utilisés dans cette activité sont fictifs. Les valeurs ont été adaptées pédagogiquement à partir de références professionnelles afin de proposer une situation réaliste. Elles ne constituent pas des recommandations individuelles d'alimentation.

3. Une donnée sans contexte est-elle vraiment utile ?

Observez la donnée suivante :

520

Que signifie ce nombre ?

À toi d’essayer avec les questions

Question 1 — 520 € ?

Question 2 — 520 kg ?

Question 3 — 520 chevaux ?

Question 4 — 520 heures ?

Question 5 — 520 litres ?

Sans contexte, il est impossible de savoir ce que cette valeur représente réellement.

Si nous écrivons maintenant :

Volcan – poids estimé : 520 kg

la donnée devient compréhensible.

Nous connaissons :

  • ce qui est mesuré : le poids ;
  • l'animal concerné : Volcan ;
  • la valeur : 520 ;
  • l'unité : kg.

Mission 4

4. Donnée ou information ?

Retenez cette différence importante :

  • Donnée : valeur brute observée, mesurée ou enregistrée.
  • Information : résultat obtenu lorsque l'on interprète une ou plusieurs données dans un contexte.

Exemple :

Donnée : 15

Donnée avec son contexte : Java a 15 ans.

Si nous comparons maintenant cette donnée avec l'âge de tous les autres chevaux :

Information : Java est le cheval le plus âgé du groupe.

Pour produire cette information, il a fallu réaliser un traitement : comparer plusieurs données.

Mission 6

6. Rendez le tableau facile à lire

Avant de commencer l'analyse, améliorez la présentation du tableau.

Vous devez essayer de :

  • mettre les titres des colonnes en évidence ;
  • adapter la largeur des colonnes ;
  • aligner correctement les données ;
  • afficher correctement les nombres décimaux ;
  • rendre le tableau facile à lire.

Vous êtes libre de choisir la présentation.

Le but n'est pas de faire le tableau le plus décoré possible mais le plus lisible possible.

Mission 9

9. À quoi sert réellement le tableur ?

Avec seulement huit chevaux, il est encore possible d'observer le tableau et de réaliser certains calculs manuellement.

Imaginez maintenant un fichier comportant :

  • 80 chevaux ;
  • 500 clients ;
  • 365 jours de relevés ;
  • plusieurs milliers de lignes de données.

Effectuer tous les calculs manuellement deviendrait beaucoup plus difficile.

C'est l'un des rôles d'un tableur.

Un tableur permet notamment de :

  • stocker des données ;
  • les organiser ;
  • effectuer automatiquement des calculs ;
  • trier et filtrer les données ;
  • rechercher certaines valeurs ;
  • créer des graphiques ;
  • comparer des résultats ;
  • aider à prendre une décision.

Le type d'une donnée est important car il détermine les traitements que l'ordinateur pourra effectuer.

Par exemple :

  • on peut calculer la moyenne des poids ;
  • on peut classer des dates dans l'ordre chronologique ;
  • on peut compter le nombre de chevaux appartenant à une catégorie ;
  • mais calculer la moyenne des noms des chevaux n'aurait aucun sens.

Mission 11

11. Données, traitement, information

Le travail réalisé aujourd'hui peut être résumé par trois étapes :

DONNÉES → TRAITEMENT → INFORMATION

Exemple 1 :

  • Données : les âges des huit chevaux.
  • Traitement : comparer les âges.
  • Information : Java est le cheval le plus âgé.

Exemple 2 :

  • Données : les quantités de foin distribuées aux huit chevaux.
  • Traitement : additionner les valeurs.
  • Information : 71,5 kg de foin sont distribués chaque jour.

Exemple 3 :

  • Données : les poids estimés des huit chevaux.
  • Traitement : calculer leur moyenne.
  • Information : le poids estimé moyen du groupe est d'environ 505,6 kg.

Mission 14

À retenir

  • Une donnée est une valeur brute observée, mesurée ou enregistrée.
  • Une donnée doit être accompagnée de son contexte pour pouvoir être correctement interprétée.
  • Une information est obtenue après avoir traité et interprété une ou plusieurs données.
  • Les données peuvent être du texte, des nombres, des dates ou des catégories.
  • Un tableur permet d'organiser et de traiter rapidement de nombreuses données.
  • Un résultat numérique ne suffit pas toujours pour prendre une décision : il faut l'interpréter dans son contexte.
  • Des données professionnelles doivent provenir de sources fiables ou être clairement identifiées comme des données simulées.
