Réponses aux activités
Mission 1

1. Bienvenue en MG1 Informatique

Lis les repères et observe ce qui est montré

Cette année, les cours d'informatique ne consisteront pas seulement à apprendre où se trouvent les boutons d'un logiciel.

Vous allez surtout apprendre à utiliser l'ordinateur pour résoudre des problèmes, organiser des informations, traiter des données et présenter des résultats.

Au cours de l'année, nous utiliserons notamment :

  • LibreOffice Calc pour organiser et traiter des données ;
  • différents outils numériques pour rechercher et exploiter des informations ;
  • des fichiers provenant de situations professionnelles ;
  • des tableaux et des graphiques ;
  • des outils permettant de communiquer ou de présenter des résultats.

La plupart du temps, vous apprendrez en faisant.

Mission 2

2. Comment allons-nous travailler ?

Lis les repères et observe ce qui est montré

En informatique, il est normal de ne pas savoir immédiatement comment réaliser quelque chose.

Vous aurez le droit :

  • d'essayer ;
  • de vous tromper ;
  • d'annuler une action ;
  • de recommencer ;
  • de chercher une solution ;
  • de demander de l'aide ;
  • d'aider un camarade sans faire le travail à sa place.

Une erreur n'est donc pas un problème.

Ce qui est important, c'est de chercher à comprendre comment la corriger.

Mission 3

3. Le document de travail

Lis les repères et observe ce qui est montré

Dans la plupart des séances, vous travaillerez dans un fichier qui sera créé dès le début du cours.

Ce fichier pourra servir :

  • de brouillon ;
  • d'espace pour essayer ;
  • pour répondre aux questions ;
  • pour réaliser les exercices ;
  • pour conserver certaines explications ;
  • pour montrer votre progression pendant la séance.

À la fin du cours, le fichier demandé devra être rendu.

Un fichier incomplet mais contenant votre travail vaut mieux qu'un fichier qui n'est pas rendu.

Mission 4

4. Avant de commencer : faisons connaissance

Lis les repères et observe ce qui est montré

Avant de travailler ensemble pendant l'année, prenons quelques minutes pour nous présenter.

À votre tour, indiquez simplement :

  • votre prénom ;
  • votre formation ou votre projet professionnel ;
  • ce que vous aimeriez faire plus tard, si vous le savez déjà ;
  • votre niveau avec un ordinateur : débutant, moyen ou à l'aise ;
  • une chose que vous savez déjà faire sur ordinateur ;
  • une chose que vous aimeriez apprendre à faire.

Il n'y a pas de bonne ou de mauvaise réponse.

Cette présentation sert simplement à mieux connaître le groupe et à adapter les activités de l'année.

Mission 5

5. Première mission : préparer son espace de travail

Lis les repères et observe ce qui est montré

Nous allons maintenant commencer à travailler sur les ordinateurs.

Dans votre espace personnel, créez un dossier nommé :

nom_prenom

Puis à l'intérieur de ce dossier, créez un sous-dossier nommé :

TIM

À l'intérieur de ce dossier, créez un nouveau dossier :

SEANCE_01

Vous devez obtenir l'organisation suivante :

TIM └── SEANCE_01

Nous utiliserons cette organisation pendant l'année afin de retrouver facilement les fichiers.

Mission 6

6. Pourquoi bien ranger ses fichiers ?

Lis les repères et observe ce qui est montré

Imaginez un ordinateur contenant plusieurs centaines de fichiers portant les noms suivants :

  • document1.odt
  • nouveau.odt
  • copie.odt
  • truc.odt
  • final.odt
  • final2.odt
  • final_vraiment.odt

Quelques semaines plus tard, retrouver le bon document devient très difficile.

Un fichier doit donc avoir un nom permettant de savoir rapidement :

  • à qui il appartient ;
  • à quel cours il correspond ;
  • ce qu'il contient.

Mission 7

7. Votre premier fichier

Lis les repères et observe ce qui est montré

Ouvrez maintenant LibreOffice Writer.

Créez un nouveau document puis enregistrez-le immédiatement dans le dossier SEANCE_01.

Le fichier doit être nommé :

BACPRO1_S01_nom_prenom.odt

Remplacez évidemment nom et prenom par vos informations.

Exemple :

BACPRO1_S01_dupont_lea.odt

Mission 8

8. Petite vérification

Lis les repères et observe ce qui est montré

Fermez maintenant votre document.

Retrouvez-le dans votre dossier puis ouvrez-le à nouveau.

Si vous avez réussi, vous venez déjà de réaliser plusieurs opérations importantes :

  • créer une arborescence de dossiers ;
  • enregistrer un fichier à un endroit précis ;
  • respecter une convention de nommage ;
  • retrouver un document enregistré.

Mission 9

9. Mission : créez votre fiche de présentation

Lis les repères et observe ce qui est montré

Dans votre document Writer, créez maintenant une petite fiche permettant de vous présenter.

Votre fiche doit comporter au minimum :

  • un titre ;
  • votre prénom ;
  • votre projet professionnel ou le métier qui vous intéresse ;
  • votre expérience avec les ordinateurs ;
  • les logiciels ou outils numériques que vous connaissez déjà ;
  • une chose que vous aimez faire ;
  • une chose que vous aimeriez apprendre en informatique cette année.

Vous pouvez ajouter d'autres informations si vous le souhaitez.

Ne mettez aucune information personnelle que vous ne souhaitez pas partager.

Mission 10

10. Première manipulation de mise en forme

Lis les repères et observe ce qui est montré

Votre document doit maintenant être organisé afin qu'il soit agréable à lire.

Essayez de réaliser les opérations suivantes :

  • agrandir le titre ;
  • mettre le titre en gras ;
  • créer au moins deux sous-titres ;
  • utiliser une liste à puces ;
  • mettre au moins une information importante en gras ;
  • modifier l'alignement d'un élément ;

Vous pouvez tester différentes possibilités.

Si le résultat ne vous plaît pas, utilisez :

Ctrl + Z

Ce raccourci permet d'annuler la dernière action.

Mission 11

11. Petit défi : peut-on apprendre sans tutoriel ?

Lis les repères et observe ce qui est montré

Ajoutez maintenant une ligne horizontale ou une bordure permettant de séparer deux parties de votre document.

Cette fois, aucune procédure détaillée n'est donnée.

Vous pouvez :

  • chercher dans les menus ;
  • tester différentes commandes ;
  • observer les icônes ;
  • demander un indice ;
  • échanger avec un camarade.

L'objectif n'est pas d'aller vite.

L'objectif est de chercher comment réaliser quelque chose que vous ne savez pas encore faire.

Mission 12

12. Petite enquête pour préparer l'année

Lis les repères et observe ce qui est montré

À la fin de votre document, ajoutez le titre :

Mon niveau en informatique

Puis recopiez les éléments suivants et indiquez pour chacun :

Je sais faire / Je pense savoir faire / Je ne sais pas encore faire

  • Créer un dossier.
  • Retrouver un fichier sur un ordinateur.
  • Renommer un fichier.
  • Utiliser une clé USB.
  • Créer un document Writer ou Word.
  • Créer un tableau.
  • Utiliser Calc ou Excel.
  • Faire un calcul dans Calc ou Excel.
  • Créer un graphique.
  • Envoyer un fichier en pièce jointe.
  • Trouver une information fiable sur Internet.
  • Utiliser un espace de stockage en ligne.

Ces réponses ne sont pas une évaluation.

Elles serviront à savoir ce que le groupe maîtrise déjà et ce qu'il faudra davantage travailler cette année.

13. Avant de rendre votre travail

Lis les repères et observe ce qui est montré

Vérifiez les points suivants :

Mission 14

À retenir

Lis les repères et observe ce qui est montré

  • Un fichier bien nommé est beaucoup plus facile à retrouver.
  • Les dossiers permettent d'organiser son travail.
  • Il est conseillé d'enregistrer son document dès le début d'une activité.
  • Ctrl + S permet d'enregistrer rapidement.
  • Ctrl + Z permet d'annuler la dernière action.
  • En informatique, essayer et se tromper font partie de l'apprentissage.
