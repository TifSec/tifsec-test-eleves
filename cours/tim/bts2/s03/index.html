Mission 3

Pourquoi allons-nous travailler cela ?

Lis les repères et observe ce qui est montré

Lors de la séance précédente, vous avez calculé des indicateurs comme le coût des intrants par hectare ou le temps de travail par hectare.

Ces indicateurs sont utiles, mais il faut encore les lire un par un pour repérer les valeurs importantes.

Lorsque le nombre de parcelles augmente, cette méthode devient lente et peut provoquer des oublis.

Nous allons donc demander au tableur de repérer automatiquement les valeurs qui dépassent un objectif fixé.

Mission 6

2. Passer d'un indicateur à une règle

Lis les repères et observe ce qui est montré

Nous avons maintenant des indicateurs fiables.

Mais un indicateur ne dit pas automatiquement s'il faut y porter attention.

Pour l'exercice, l'exploitant fixe l'objectif interne suivant :

le coût des intrants ne doit pas dépasser 400 €/ha.

Attention : 400 €/ha est une valeur fictive choisie uniquement pour apprendre à construire l'outil. Ce n'est pas une norme agricole.

Nous pouvons traduire cette règle en langage courant :

SI le coût par hectare dépasse 400 €, ALORS afficher « À surveiller », SINON afficher « OK ».

Dans la feuille Analyse, ajoutez une nouvelle colonne nommée :

Alerte coût

Avant d'utiliser Calc, complétez dans votre tête :

  • condition : ................................................................................................................
  • si la condition est vraie : ................................................................................................................
  • si la condition est fausse : ................................................................................................................

Mission 7

3. Traduire la règle dans Calc

Lis les repères et observe ce qui est montré

La fonction SI permet au tableur de choisir entre deux résultats selon qu'une condition est vraie ou fausse.

Sa structure générale est :

=SI(condition;résultat_si_vrai;résultat_si_faux)

Si votre coût par hectare se trouve en I2, essayez de construire la formule permettant d'afficher :

  • À surveiller si I2 dépasse 400 ;
  • OK dans le cas contraire.

Indice 1

Commencez par écrire uniquement la condition : est-ce que I2 est supérieur à 400 ?

Indice 2

Utilisez la structure =SI(condition;"À surveiller";"OK").

Indice 3

Une formule possible est =SI(I2>400;"À surveiller";"OK").

Mission 9

5. Faire pointer la formule vers le paramètre

Lis les repères et observe ce qui est montré

Nous allons maintenant remplacer le nombre 400 dans la formule par la cellule contenant ce paramètre.

Mais une difficulté apparaît : lorsque nous recopions une formule vers le bas, Calc déplace normalement les références de cellules.

Par exemple :

  • I2 devient I3 sur la ligne suivante ;
  • puis I4, etc.

C'est utile pour le coût de chaque parcelle.

En revanche, notre cellule contenant 400 doit rester toujours la même.

Pour bloquer une référence, on utilise les signes $.

Une référence comme :

$B$2

est appelée une référence absolue.

Modifiez votre formule afin qu'elle utilise la cellule de la feuille Parametres contenant 400.

Indice 1

La cellule contenant le coût maximum doit rester identique lorsque vous recopiez la formule.

Indice 2

Utilisez les signes $ devant la colonne et devant le numéro de ligne du paramètre.

Indice 3

Si le 400 se trouve en B2 de Parametres, la comparaison peut utiliser $Parametres.$B$2.

Mission 13

9. Faire le lien entre les étapes

Lis les repères et observe ce qui est montré

Lors de la séance précédente, nous avions :

données → vérification → indicateurs.

Aujourd'hui, nous avons ajouté :

indicateurs → comparaison à un objectif → alerte automatique.

Notre chaîne devient donc :

données → vérification → indicateurs → règle → alerte.

La prochaine étape sera de croiser plusieurs alertes pour faire apparaître des niveaux de priorité.

Mission 16

À retenir

Lis les repères et observe ce qui est montré

  • La fonction SI permet d'appliquer automatiquement une règle simple.
  • Une condition peut être vraie ou fausse.
  • Un paramètre permet de modifier facilement la règle sans réécrire toutes les formules.
  • Une référence absolue reste fixe lorsque la formule est recopiée.
  • Une alerte signale un dépassement ; elle n'explique pas sa cause.
  • Automatiser le repérage d'une situation ne signifie pas automatiser la décision.
