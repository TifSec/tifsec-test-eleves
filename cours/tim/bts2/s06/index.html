Mission 3

Pourquoi allons-nous travailler cela ?

Lis les repères et observe ce qui est montré

Lors de la séance précédente, nous avons réussi à calculer :

  • le nombre de parcelles prioritaires ;
  • la surface totale en maïs ensilage ;
  • le rendement moyen du maïs ensilage.

Pour cela, nous avons écrit des formules avec NB.SI, SOMME.SI et MOYENNE.SI.

Cette méthode fonctionne très bien lorsque nous savons exactement quelle question nous voulons poser.

Mais si nous voulons maintenant comparer toutes les cultures, il faudrait recommencer les calculs pour Prairie permanente, Prairie temporaire, Méteil, Maïs ensilage...

Il existe un outil capable de réaliser automatiquement ce regroupement : la table dynamique.

Mission 4

À quoi cela va-t-il vous servir ?

Lis les repères et observe ce qui est montré

Une table dynamique permet de transformer rapidement un grand tableau détaillé en une vue plus simple.

Elle peut servir par exemple à :

  • regrouper des parcelles par culture ;
  • comparer des surfaces ;
  • calculer des valeurs moyennes ;
  • résumer des coûts ou des temps de travail ;
  • modifier rapidement le point de vue utilisé pour analyser les données.

Mission 8

4. Créer la table dynamique

Lis les repères et observe ce qui est montré

Dans la feuille Analyse :

  1. sélectionnez tout le tableau, titres compris ;
  2. ouvrez Données → Table dynamique → Insérer ou éditer ;
  3. choisissez Sélection active ;
  4. validez.

LibreOffice affiche maintenant les noms des colonnes sous forme de champs que vous pouvez déplacer.

Ressource : LibreOffice – Création de tables dynamiques.

Mission 12

8. Pourquoi ajouter maintenant le coût et le temps de travail ?

Lis les repères et observe ce qui est montré

Nous savons maintenant comparer les cultures selon leur surface et leur rendement.

Mais depuis le début de notre analyse, nous savons qu'une performance ne se résume pas à la quantité produite.

Nous allons donc ajouter deux autres dimensions :

  • le coût des intrants par hectare ;
  • le temps de travail par hectare.

Nous passons donc d'une comparaison principalement productive à une lecture plus large de la situation.

  4. remettez ensuite Culture comme champ de ligne.

12. Tester l'actualisation

Lis les repères et observe ce qui est montré

Une table dynamique est liée à ses données sources, mais elle ne se met pas toujours à jour immédiatement lorsque celles-ci changent.

Dans la feuille Analyse, modifiez temporairement la surface de P01 :

7,8 ha → 10 ha

Retournez dans votre table dynamique puis utilisez :

Données → Table dynamique → Actualiser

Observez la surface totale des prairies permanentes.

Remettez ensuite P01 à 7,8 ha et actualisez à nouveau.

Mission 17

13. Faire le lien avec la séance précédente

Lis les repères et observe ce qui est montré

En S05, nous avions :

une question précise → une fonction conditionnelle → un résultat.

Exemple :

Maïs ensilage → SOMME.SI → 15,3 ha.

Aujourd'hui :

un tableau complet → un critère de regroupement → plusieurs indicateurs pour toutes les catégories.

Les deux méthodes sont utiles :

  • les fonctions sont pratiques pour construire des indicateurs précis à des endroits choisis ;
  • la table dynamique est pratique pour explorer, regrouper et comparer rapidement un ensemble de données.

Mission 20

À retenir

Lis les repères et observe ce qui est montré

  • Une table dynamique permet de regrouper et synthétiser rapidement des données.
  • Le champ de ligne définit les catégories à comparer.
  • Les champs de données définissent les indicateurs à calculer.
  • Le choix entre somme, moyenne ou autre calcul dépend de la question posée.
  • La table dynamique ne modifie pas les données sources.
  • Après une modification des données sources, il peut être nécessaire d'actualiser la table.
  • Une synthèse automatique facilite l'analyse, mais elle ne remplace pas l'interprétation professionnelle.
