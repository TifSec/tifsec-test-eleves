Mission 8

3. Construire des indicateurs – 3 points

Lis les repères et observe ce qui est montré

Nous avons vérifié les données. Nous pouvons maintenant les transformer en indicateurs comparables.

Copiez dans la feuille Analyse les colonnes :

  • Parcelle ;
  • Culture ;
  • Surface ;
  • Production ;
  • Coût intrants ;
  • Temps de travail.

Corrigez Prairie temp. en Prairie temporaire.

Ajoutez puis calculez automatiquement les trois indicateurs suivants :

  1. Rendement (t MS/ha)
  2. Coût intrants (€/ha)
  3. Temps de travail (h/ha)

Pourquoi passer à ces indicateurs ? Les parcelles n'ont pas toutes la même surface. Ramener les valeurs à l'hectare permet de les comparer plus justement.

Mission 9

4. Automatiser une première règle – 3 points

Lis les repères et observe ce qui est montré

Nous disposons maintenant d'un coût par hectare.

L'exploitation fixe pour cet exercice l'objectif interne suivant :

Coût intrants maximum : 400 €/ha

Cette valeur est fictive et ne constitue pas une recommandation agricole.

Pourquoi cette partie ? Lorsqu'un tableau comporte de nombreuses lignes, il est plus fiable de faire appliquer automatiquement une règle que de vérifier chaque valeur manuellement.

Dans une zone libre de la feuille Analyse, inscrivez le paramètre 400 €/ha.

Ajoutez une colonne Alerte coût.

Créez une formule permettant d'afficher :

  • À surveiller lorsque le coût dépasse le paramètre ;
  • OK sinon.

La formule doit utiliser une référence absolue vers le paramètre.

Mission 10

5. Croiser deux critères – 3 points

Lis les repères et observe ce qui est montré

Nous allons maintenant tenir compte d'un deuxième indicateur :

Temps de travail maximum : 9 h/ha

Pourquoi passer à deux critères ? Une situation professionnelle dépend rarement d'une seule valeur. Croiser plusieurs informations permet de faire ressortir les situations cumulant plusieurs points de vigilance.

Ajoutez ce deuxième paramètre dans votre zone de paramètres.

Ajoutez une colonne Priorité et appliquez la règle suivante :

  • Prioritaire si le coût dépasse 400 €/ha ET le temps de travail dépasse 9 h/ha ;
  • À surveiller si un seul des deux critères est dépassé ;
  • OK si aucun des deux critères n'est dépassé.

Choisissez vous-même les fonctions adaptées.

Mission 11

6. Produire des indicateurs de synthèse – 3 points

Lis les repères et observe ce qui est montré

Nous avons analysé chaque ligne. Nous allons maintenant résumer l'ensemble du tableau.

Pourquoi changer d'échelle ? Un responsable a souvent besoin de quelques indicateurs globaux plutôt que de relire toutes les parcelles une par une.

Dans la feuille Synthese, calculez automatiquement :

  1. le nombre de parcelles Prioritaires ;
  2. la surface totale en Maïs ensilage ;
  3. le rendement moyen du Maïs ensilage.

Choisissez vous-même la fonction adaptée pour chaque calcul.

Mission 12

7. Réaliser une table dynamique – 2 points

Lis les repères et observe ce qui est montré

Les fonctions précédentes répondent à trois questions précises.

Nous voulons maintenant comparer toutes les cultures sans écrire une série de nouvelles formules.

Pourquoi passer à une table dynamique ? Elle permet de regrouper automatiquement les données par catégorie et de produire plusieurs indicateurs en une seule synthèse.

À partir de la feuille Analyse, créez une table dynamique permettant d'afficher pour chaque culture :

  • la surface totale ;
  • le rendement moyen.

Placez cette table dans la feuille Synthese, sous les indicateurs précédents.

Mission 13

8. Présenter le résultat – 2 points

Lis les repères et observe ce qui est montré

Nous disposons maintenant d'une synthèse numérique.

Nous voulons permettre à un responsable de comparer rapidement les rendements moyens des différentes cultures.

Pourquoi passer à un graphique ? Une représentation visuelle permet de repérer plus rapidement les écarts entre catégories.

À partir de votre table dynamique, créez un graphique adapté à cette question.

Il doit comporter :

  • un type de graphique pertinent ;
  • un titre explicite ;
  • les noms des cultures ;
  • l'unité t MS/ha.

Mission 16

Après cette évaluation

Lis les repères et observe ce qui est montré

Nous allons changer de type de problème.

Jusqu'ici, toutes nos données tenaient dans un même tableur.

Nous allons maintenant nous demander comment organiser des informations lorsqu'elles deviennent plus nombreuses, qu'elles concernent plusieurs types d'objets et qu'elles doivent être reliées entre elles.

Nous commencerons donc la prochaine fois à travailler sur les bases de données relationnelles.
