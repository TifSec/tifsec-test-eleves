Mission 4À commencer

2. À quoi sert une extension ? – 5 minutes

Lis les repères et observe ce qui est montré

La partie située à la fin du nom d'un fichier, généralement après un point, s'appelle son extension.

Elle permet notamment d'identifier son format.

ExtensionType de fichierExemple de logiciel
.odtDocument texte OpenDocumentLibreOffice Writer
.odsClasseur OpenDocumentLibreOffice Calc
.odpPrésentation OpenDocumentLibreOffice Impress
.pdfDocument destiné notamment à la consultationNavigateur ou lecteur PDF
.jpg / .pngImageVisionneuse d'image / navigateur

À toi d’essayer avec les questions

Question 1 — Question 2 : quelle extension utiliseriez-vous pour :

un document Writer que vous souhaitez encore modifier ;

un tableau créé avec Calc ;

une présentation créée avec Impress ;

Question 2 — une version terminée d'un document destinée surtout à être consultée ?

AIDE SI BESOIN – Choisir l'extension

Indice 1/3 : regardez le tableau situé juste au-dessus.

Indice 2/3 : Writer, Calc et Impress n'utilisent pas la même extension.

Indice 3/3 : Writer = .odt, Calc = .ods, Impress = .odp, consultation = souvent .pdf.

Mission 5À commencer

3. Construire une arborescence – 10 minutes

Lis les repères et observe ce qui est montré

Quand tous les fichiers sont placés au même endroit, il devient difficile de retrouver rapidement son travail.

Une solution consiste à créer une arborescence de dossiers.

Dans votre espace personnel, créez l'organisation suivante :

TIM └── 4e3e ├── Cours ├── Travaux │ └── S03 └── Ressources

AIDE SI BESOIN – Créer l'arborescence

Indice 1/3 : commencez uniquement par créer le dossier TIM.

Indice 2/3 : ouvrez ensuite TIM avant de créer 4e3e.

Indice 3/3 : dans 4e3e, créez Cours, Travaux et Ressources. Entrez ensuite dans Travaux pour créer S03.

Mission 8À commencer

6. Même document, deux formats – 5 minutes

Lis les repères et observe ce qui est montré

Votre fichier est actuellement au format ODT.

Il s'agit de votre fichier de travail Writer.

Nous allons maintenant créer une version au format PDF.

  1. Enregistrez d'abord votre travail avec Ctrl + S.
  2. Utilisez la fonction d'export au format PDF.
  3. Enregistrez le PDF dans le même dossier S03.
  4. Nommez-le 4e3e_S03_nom_prenom.pdf.

7. Retrouver son fichier – 5 minutes

Lis les repères et observe ce qui est montré

Fermez LibreOffice Writer.

Revenez dans le dossier TIM.

Sans utiliser la liste des fichiers récents :

  1. retrouvez votre dossier S03 ;
  2. retrouvez votre fichier ODT ;
  3. ouvrez-le ;
  4. ajoutez à la fin : Je sais retrouver un fichier dans une arborescence.
  5. enregistrez avec Ctrl + S.

AIDE SI BESOIN – Retrouver le fichier

Indice 1/3 : commencez dans le dossier TIM.

Indice 2/3 : souvenez-vous que votre travail se trouve dans le dossier Travaux.

Indice 3/3 : suivez TIM → 4e3e → Travaux → S03.

Mission 12

À retenir

Lis les repères et observe ce qui est montré

  • Un dossier sert à organiser des fichiers et d'autres dossiers.
  • Un fichier contient des données.
  • L'extension indique le format d'un fichier.
  • Une arborescence permet de ranger les documents de manière logique.
  • Un nom de fichier précis permet de retrouver et d'identifier plus facilement son travail.
  • Un fichier ODT peut servir de document de travail dans Writer.
  • Une version PDF peut être créée pour faciliter la consultation ou la transmission.
  • Je dois être capable de retrouver un fichier sans dépendre uniquement de la liste des documents récents.
