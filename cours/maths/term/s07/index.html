Comparer deux prestations et justifier une décision

Thème du programme

modèle mathématique.

Le problème à résoudre

Comparer deux prestations et justifier une décision

Ce que tu vas apprendre

  • Comprendre pourquoi le prestataire le moins cher peut changer selon les besoins.
  • Comparer une fonction affine et une fonction du second degré.
  • Comprendre ce que signifie l'égalité entre deux fonctions.
  • Prendre une décision professionnelle en respectant un budget.

Ce que tu vas apprendre à faire

  • Calculer les coûts de deux entreprises pour une même fréquence.
  • Compléter et interpréter un tableau comparatif.
  • Retrouver les valeurs pour lesquelles deux coûts sont identiques.
  • Vérifier plusieurs contraintes simultanément.
  • Rédiger une recommandation argumentée.

Pourquoi cette séance ?

Objectif de cette séance : Comprendre pourquoi le prestataire le moins cher peut changer selon les besoins.

Dans la vie quotidienne

Utilise les situations et les documents de la séance pour mettre les notions en pratique.

Pour commencer

Reprends les méthodes des séances précédentes si elles te sont utiles ; les rappels du cours t’accompagnent.

Notre situation professionnelle

Un centre équestre souhaite confier l'entretien mensuel de sa carrière à une entreprise extérieure.

Deux prestataires proposent des tarifs différents. Le responsable doit comparer les offres pour choisir celle qui correspond le mieux à ses besoins.

Problème : quelle entreprise choisir selon le nombre d'interventions nécessaires ?

Les modèles de coûts sont fictifs. Les prestations sont supposées équivalentes pour permettre une comparaison mathématique.

Séance 5 : une fonction du second degré peut posséder un minimum.

Séance 6 : les équations, les inéquations et les contraintes permettent de rechercher des solutions admissibles.

Cours magistral puis exercices

Fiche papier — Comparer deux offres et résoudre une égalité

Cette fiche t’aide à suivre une méthode sans donner les réponses de la séance. Une ligne de calcul = une transformation expliquée.

1. Avant de calculer

Repère ce que signifie x, les deux formules, leurs unités et les contraintes du problème. Comme deux tarifs, les offres doivent être comparées pour le même nombre d’interventions.

  1. Écris ce que représente x.
  2. Repère les frais fixes et les frais qui dépendent de x.
  3. Note les valeurs autorisées par l’énoncé.

2. Calculer puis comparer

Pour un nombre précis, remplace x dans les deux formules. Écris les opérations dans l’ordre et garde l’unité en euros.

  1. Exemple de méthode : A(3) = 20 × 3 + 100.
  2. = 60 + 100.
  3. = 160 €.
  4. Calcule ensuite B(3) séparément. Ne compare pas une offre calculée pour x = 3 à une autre calculée pour x = 4.

3. Trouver les nombres pour lesquels les offres sont égales

Avec A(x) = 20x + 100 et B(x) = 5(x − 4)² + 180, écrire A(x) = B(x) signifie que l’on cherche les points de rencontre.

  1. 20x + 100 = 5(x − 4)² + 180.
  2. Développer le carré : (x − 4)² = x² − 8x + 16.
  3. Distribuer 5 : 5x² − 40x + 80.
  4. Ajouter 180 : B(x) = 5x² − 40x + 260.
  5. Regrouper dans une même expression : 0 = 5x² − 60x + 160.
  6. Mettre 5 en facteur : 0 = 5(x² − 12x + 32).
  7. Factoriser : 0 = 5(x − 4)(x − 8).

4. Utiliser la règle du produit nul

Si deux facteurs multipliés donnent zéro, au moins l’un des facteurs vaut zéro. C’est comme deux interrupteurs en série : le produit est nul si l’un est coupé.

  1. Résous (x − 4)(x − 8) = 0 en séparant les deux possibilités.
  2. Vérifie chaque solution en la remplaçant dans les deux offres.
  3. Garde seulement les solutions qui respectent les contraintes du problème.

5. Rédiger le conseil

La bonne offre dépend du nombre d’activités et des contraintes. Une solution d’équation est un point d’égalité, pas automatiquement la meilleure décision.

  1. Indique les effectifs où les prix sont égaux.
  2. Compare les coûts de part et d’autre.
  3. Rédige une recommandation avec une justification.

Je m’entraîne — même méthode que dans le cours

Reprends les étapes de l’exemple juste au-dessus. Écris une ligne par étape et garde les unités.

  1. Avec les offres A(x) = 20x + 100 et B(x) = 5(x − 4)² + 180, calcule séparément A(3) et B(3).
  2. Développe B(x) en écrivant la transformation de (x − 4)² puis la distribution de 5.
  3. Résous 5(x − 4)(x − 8) = 0 en séparant les deux facteurs.

Je transfère — une situation nouvelle

Cette fois, les nombres ou le contexte changent. Commence par identifier ce que l’on cherche, puis choisis la méthode qui convient.

  1. Deux offres sont U(x) = 15x + 80 et V(x) = 3(x − 5)² + 120. Écris l’égalité U(x) = V(x).
  2. Développe, regroupe, puis cherche si une factorisation est possible.
  3. Vérifie les solutions dans le contexte et rédige un conseil.

Lis les repères et observe ce qui est montré

Notion : modèle mathématique.

Qu'est-ce que c'est ? Un modèle mathématique est une formule qui représente une situation de manière simplifiée.

À quoi ça sert ? Il permet de prévoir et de comparer des coûts sans avoir à réaliser toutes les prestations.

Deux entreprises proposent les modèles suivants :

EntrepriseCoût mensuelType de fonction
AA(x) = 20x + 100Affine
BB(x) = 5(x - 4)² + 180Second degré

x représente le nombre d'interventions mensuelles, entier compris entre 1 et 8. Les coûts sont exprimés en euros.

Entreprise A : le modèle comprend 100 € de coût fixe et 20 € supplémentaires par intervention.

Entreprise B : le modèle possède un minimum de 180 € pour quatre interventions. Il s'agit d'un forfait fictif dont le coût varie selon l'écart à quatre interventions.

4. Comprendre les points d'égalité

Lis les repères et observe ce qui est montré

Notion : équation et produit nul.

Qu'est-ce que c'est ? Pour savoir quand deux entreprises facturent le même montant, nous recherchons les valeurs pour lesquelles A(x) = B(x).

À quoi ça sert ? Cela permet de déterminer précisément quand deux modèles sont équivalents.

Une analogie : sur un graphique, les deux courbes se rencontrent aux endroits où elles ont la même hauteur pour la même valeur de x.

Pourquoi cette activité ? Nous allons comprendre le raisonnement algébrique qui permet de retrouver les égalités du tableau.

Durée indicative : 12 minutes. Calculatrice autorisée.

Étape 2 : Développer le carré

Lis les repères et observe ce qui est montré

Nous savons que :

Mission 10

Étape 4 : Factoriser

Lis les repères et observe ce qui est montré

Nous pouvons écrire :

x² - 12x + 32 = (x - 4)(x - 8)

Pourquoi ? Vérifions en développant :

(x - 4)(x - 8) = x² - 8x - 4x + 32

Nous retrouvons bien :

x² - 12x + 32

Mission 11

Étape 5 : Utiliser la règle du produit nul

Lis les repères et observe ce qui est montré

Nous obtenons :

(x - 4)(x - 8) = 0

Un produit est nul si au moins un de ses facteurs est nul.

Nous cherchons donc :

x - 4 = 0 ou x - 8 = 0

Les solutions sont :

x = 4 ou x = 8
