Notre problème professionnel

Un centre équestre souhaite organiser une journée de découverte. Deux organisations sont possibles, avec des tarifs et des dépenses différents.

Le responsable veut choisir celle qui donne le meilleur résultat financier.

Question : faut-il toujours choisir l'organisation qui coûte le moins cher au départ ?

Le lien avec la séance précédente

En séance 3, nous avons appris à calculer le résultat financier d'une journée équestre et à déterminer son seuil de rentabilité.

Nous avions obtenu la formule B(x) = 33x - 396, où x représente le nombre de participants.

Aujourd'hui, nous allons conserver ce premier modèle, en construire un deuxième, puis les comparer.

Ce qui change : nous ne cherchons plus seulement à savoir si une activité est rentable, mais laquelle de deux organisations est la plus avantageuse selon le nombre de participants.

Ce que je dois savoir faire

  • Reconnaître une fonction affine sous la forme f(x) = ax + b.
  • Expliquer le rôle de a et de b dans une situation professionnelle.
  • Calculer les images d'une fonction.
  • Comparer deux modèles à l'aide d'une équation.
  • Déterminer quand un modèle est préférable à l'aide d'une inéquation.
  • Interpréter un seuil théorique avec des valeurs entières.
  • Justifier une recommandation professionnelle.

Cours magistral puis exercices

Fiche papier — Comparer deux organisations avec des fonctions affines

Une fonction affine décrit un coût qui comporte souvent une part fixe et une part qui augmente avec l’activité.

1. Lire la formule comme un tarif

Dans f(x) = ax + b, x est le nombre d’activités, a est le coût ajouté à chaque activité et b est le coût fixe, même si x vaut zéro.

Exemple : A(x) = 20x + 100.
20 € s’ajoutent par activité.
100 € sont payés au départ.

2. Calculer un coût

Pour calculer une image, remplace x par le nombre demandé. Respecte les priorités : multiplication avant addition.

  1. Pour x = 4 : A(4) = 20 × 4 + 100.
  2. = 80 + 100.
  3. = 180 €.

3. Trouver le point de bascule

Le point de bascule est le nombre d’activités pour lequel les deux organisations coûtent pareil. On écrit donc une égalité.

  1. A(x) = 20x + 100 ; B(x) = 30x + 40.
  2. 20x + 100 = 30x + 40.
  3. On retire 20x : 100 = 10x + 40.
  4. On retire 40 : 60 = 10x.
  5. On divise par 10 : x = 6.
  6. À 6 activités, les coûts sont égaux. Ensuite, compare les deux prix pour savoir laquelle est la moins chère.

4. Conseiller sans oublier le contexte

Une formule peut donner un résultat juste mais impossible dans la réalité. Le nombre d’activités doit respecter le minimum, le maximum et le budget.

  1. Calcule les deux coûts pour le nombre demandé.
  2. Vérifie les contraintes.
  3. Écris une phrase qui nomme l’offre choisie et explique pourquoi.

Je m’entraîne — même méthode que dans le cours

Reprends les étapes de l’exemple juste au-dessus. Écris une ligne par étape et garde les unités.

  1. Avec A(x) = 20x + 100, calcule A(6) en écrivant les étapes.
  2. Avec B(x) = 30x + 40, cherche quand A(x) = B(x).
  3. Interprète le nombre obtenu avec une phrase.

Je transfère — une situation nouvelle

Cette fois, les nombres ou le contexte changent. Commence par identifier ce que l’on cherche, puis choisis la méthode qui convient.

  1. Deux prestataires proposent P(x) = 18x + 90 et Q(x) = 24x + 42. Trouve le nombre x pour lequel les tarifs sont égaux.
  2. Compare les deux coûts pour x = 3, puis pour x = 10.
  3. Quelle offre recommandes-tu selon le nombre d’activités ? Justifie.

Mission 5

3. Comprendre les fonctions affines

Lis les repères et observe ce qui est montré

Notion : fonction affine et sens de variation.

Qu'est-ce que c'est ? Une fonction affine est une fonction qui peut s'écrire sous la forme f(x) = ax + b, où a et b sont deux nombres.

À quoi ça sert ? À représenter une quantité qui augmente ou diminue régulièrement lorsque la valeur d'entrée change.

Les deux coefficients

Dans f(x) = ax + b :

a indique de combien le résultat varie lorsque x augmente de 1.

b représente le résultat obtenu lorsque x = 0.

Si a est positif, la fonction est croissante. Si a est négatif, elle est décroissante. Si a est nul, elle est constante.

Nous utilisons les fonctions :

BA(x) = 33x - 396 et BB(x) = 28x - 310.

Durée indicative : 10 minutes. Calculatrice autorisée.

Mission 8

4. Déterminer le point de bascule

Lis les repères et observe ce qui est montré

Notion : égalité de deux fonctions affines.

Qu'est-ce que c'est ? Le point de bascule est le moment où deux modèles donnent le même résultat. Avant ce point, l'un peut être préférable ; après, l'autre peut devenir plus avantageux.

À quoi ça sert ? À déterminer précisément quand une décision doit changer selon la fréquentation.

Pourquoi résoudre une équation ?

Nous cherchons le nombre de participants pour lequel les deux résultats financiers sont égaux.

Ce que cela vous apporte : savoir comparer deux situations sans effectuer une longue série d'essais.

Durée indicative : 10 minutes. Calculatrice autorisée.

Mission 11

5. Conseiller le responsable

Lis les repères et observe ce qui est montré

Notion : inéquation du premier degré.

Qu'est-ce que c'est ? Une inéquation ressemble à une équation, mais utilise un signe de comparaison : <, >, ≤ ou ≥.

À quoi ça sert ? À déterminer toutes les valeurs qui respectent une condition, par exemple les nombres de participants pour lesquels une organisation rapporte davantage qu'une autre.

Pourquoi utiliser une inéquation ?

Nous ne cherchons plus uniquement le point d'égalité. Nous voulons identifier toute la plage de fréquentation pour laquelle A donne un meilleur résultat.

Ce que cela vous apporte : savoir prendre une décision à partir d'une condition et non d'un seul calcul.

Le responsable prévoit entre 12 et 20 participants.

Durée indicative : 7 minutes. Calculatrice autorisée.

À retenir

Lis les repères et observe ce qui est montré

  • Une fonction affine s'écrit f(x) = ax + b.
  • Le coefficient a indique la variation du résultat lorsque x augmente de 1.
  • Le coefficient b représente la valeur de la fonction pour x = 0.
  • Si a est positif, la fonction est croissante ; s'il est négatif, elle est décroissante.
  • Une équation permet de rechercher quand deux modèles sont égaux.
  • Une inéquation permet de rechercher quand un modèle est plus avantageux.
  • Une solution doit respecter les contraintes de la situation professionnelle.
