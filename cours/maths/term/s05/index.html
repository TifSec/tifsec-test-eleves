Découvrir les fonctions du second degré

Thème : Mathématiques — Fonctions et variations

Problématique : Comment décrire une quantité qui diminue, puis augmente ?

Pourquoi étudier ce sujet ?

Une fonction affine ne décrit pas toutes les évolutions. Le terme x² permet de construire d’autres modèles.

Dans la vie quotidienne

Comparer les valeurs d’un indicateur de coût selon un niveau d’activité, dans un modèle fictif.

Pour commencer

La séance 4 portait sur les fonctions affines, de la forme ax + b. Cherche aujourd’hui ce qui change quand x² apparaît.

Ce qui va nous servir

  • Calculer une image en remplaçant x par un nombre.
  • Reconnaître une expression de la forme ax + b.

Les repères pour comprendre

Le carré

x² signifie x × x. Par exemple, pour x = 4, x² = 4 × 4. Dans 2x², on calcule le carré, puis on multiplie le résultat par 2.

Second degré

Une fonction du second degré s’écrit f(x) = ax² + bx + c, avec a différent de 0. Si a = 0, le terme en x² disparaît : on retrouve une fonction affine.

Lire un tableau

Un tableau donne les images des valeurs choisies. Pour dire que les images diminuent ou augmentent, lis-les de gauche à droite quand x augmente. Le plus petit résultat du tableau n’est pas forcément le minimum de la fonction sur tous les nombres.

Ce que vous allez apprendre

  • Reconnaître la forme ax² + bx + c avec a non nul.
  • Distinguer un carré et une multiplication par 2.

Ce que vous allez apprendre à faire

  • Calculer des images et construire un tableau de valeurs.
  • Comparer des valeurs et décrire une évolution.
  • Interpréter un résultat dans les limites du modèle.

Activité 3 — Calculer les images

Pourquoi cette activité ? Voir comment évoluent les résultats d’une même fonction.

Comment procéder ?

  1. On utilise maintenant f(x) = x² − 4x + 5. La calculatrice est autorisée.
  2. Calcule chaque image en remplaçant x par le nombre indiqué.
  3. Pour f(3), garde une ligne de calcul afin de montrer ta démarche.

Exemple de méthode pour f(6) : remplace tous les x par 6 dans 6² − 4 × 6 + 5. Calcule d’abord le carré et la multiplication, puis les additions et soustractions.

À retenir

    Faire le point

    Une fonction du second degré comporte un terme ax² avec a non nul. Pour calculer une image, remplace tous les x par le même nombre et respecte les priorités. Un tableau permet de comparer les valeurs testées ; il ne suffit pas à prouver une propriété pour tous les nombres.
